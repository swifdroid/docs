# Source Map

Durable navigation map for the docs repository. Verify exact current paths before mutation.

- `mkdocs.yml` - site configuration and publication navigation
- `docs/index.md` - site landing page
- `docs/release-notes.md` - public release notes
- `docs/app/` - Droid application/framework documentation
- `docs/app/classic/` - classic Android view/widget pages
- `docs/app/x/` - AndroidX pages
- `docs/app/material/` - Material component pages
- `docs/jni-kit/` - JNIKit documentation
- `docs/lib/` - library-authoring/distribution documentation
- `.agent/WRITING_GUIDELINE.md` - page voice/structure/example policy
- `.agent/PLAN.md` - approved executable documentation coverage
- `.agent/TODO.md` - deferred/unverified/blocked coverage
- `.agent/DONE.md` - compact completed outcomes
- `.agent/IMPLEMENTED_MAP.md` - verified page-to-source evidence

Owning source normally lives in sibling repositories (`../droid`, `../jni-kit`, `../core-libs`) but exact paths/branches/state must be verified at task time.
