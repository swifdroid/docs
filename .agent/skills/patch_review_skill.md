# Patch Review Skill

Use for independent review of a docs patch without granting mutation authority.

1. Re-establish exact page/nav/tracking scope.
2. Inspect actual patch and exact owning source for material technical claims.
3. Check writing guideline compliance, example accuracy, links, nav reachability, and tracking-state transitions.
4. Run/inspect strict MkDocs build evidence when appropriate.
5. Report findings with exact page/source evidence.
6. Review does not authorize edits, sibling mutation, staging, commit, or broad cleanup.
