# Master Plan

Repository capability roadmap for SwifDroid documentation.

1. Keep core getting-started/setup/library/JNIKit documentation aligned with verified source and supported workflow.
2. Expand coherent classic Droid API documentation only where source implementation is verified.
3. Expand coherent AndroidX and Material documentation in step with verified Droid coverage.
4. Keep navigation and page-to-source evidence internally consistent as coverage grows.
5. Keep examples practical, current, and source-verifiable.
6. Maintain a sustainable source-change -> targeted docs-audit -> page/tracking synchronization loop.

This roadmap is direction, not executable authorization. Approved page work lives in `PLAN.md`; deferred work lives in `TODO.md`.
