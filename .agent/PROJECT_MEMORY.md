# Project Memory

Durable current-state facts for docs agents.

- This is an independent Git repository for the SwifDroid Material for MkDocs public site.
- Documentation is a projection of verified Droid/JNIKit/core-libs behavior, not semantic authority.
- `mkdocs.yml` owns published navigation.
- `WRITING_GUIDELINE.md` owns page voice/structure/example quality.
- `PLAN/TODO/DONE/IMPLEMENTED_MAP` form an existing documentation tracking system with distinct roles.
- The repository can contain large staged+unstaged documentation work; preserve those layers.
- Parent `../SwifDroid` governance is optional coordination context, not required local context.

Do not persist transient Git snapshots, local preview ports, source checkout state, or one-off audit notes here.
