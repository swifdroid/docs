# Loading indicator

Material loading indicators signal indeterminate work with Material motion.

**Droid does not wrap Material loading-indicator APIs at the current source pin.** Classic [`ProgressBar`](../classic/progress-bar.md) is a placeable control for layout purposes.

## Use it when…

Do not plan Material loading-indicator UI against Droid yet.

## How it behaves

There is no Material loading-indicator constructor or show/hide helper at this pin.

## Notes

This page will grow only after a live Material loading-indicator wrapper lands in a commit pin with real methods.
