# Icon button

Material icon buttons are compact actions drawn as icons with Material ripple.

**Droid does not wrap Material icon-button APIs at the current source pin.** There is no live Material icon-button Swift type.

## Use it when…

Do not plan Material icon-button chrome against Droid yet. Use [`MaterialButton`](button.md) or classic [`ImageButton`](../../classic/image-button.md) (placement only).

## How it behaves

There is no Material icon-button constructor, icon/ripple API, or checked-icon state at this pin.

This page will grow only after a live Material icon-button wrapper lands in a commit pin with real methods.
