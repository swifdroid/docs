# FAB menu

FAB menu is the Material pattern of a primary FAB that opens a small menu of secondary actions.

**Droid does not wrap Material FAB-menu APIs at the current source pin.** There is no live FAB-menu Swift type.

## Use it when…

Do not plan FAB-menu UI against Droid yet. Place one [`FloatingActionButton`](fabs.md) and drive secondary actions from ordinary buttons.

## How it behaves

There is no FAB-menu constructor, open/close animation API, or sub-action listener at this pin.
