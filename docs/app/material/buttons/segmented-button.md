# Segmented button

Segmented buttons are Material’s multi-option selection group drawn as connected segments.

**Droid does not wrap Material segmented-button APIs at the current source pin.** There is no live segmented-button Swift type.

## Use it when…

Do not plan segmented-button UI against Droid yet. Use [`RadioGroup`](../../classic/radio-group.md) for exclusive choice or several [`MaterialButton`](button.md) controls.

## How it behaves

There is no segmented-button constructor, selection API, or segment listener at this pin.
