# Button groups

Material button groups present related actions as a connected row or grid.

**Droid does not wrap Material button-group APIs at the current source pin.** `MaterialButtonToggleGroup` is namespace-only (wrapper type not live).

## Use it when…

Do not plan Material button-group UI against Droid yet. Lay out several [`MaterialButton`](button.md) controls side by side.

## How it behaves

There is no `MaterialButtonToggleGroup()` constructor, single-selection API, or group listener at this pin.
