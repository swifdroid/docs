# Split button

Split buttons combine a primary action with a secondary dropdown or toggle region.

**Droid does not wrap Material split-button APIs at the current source pin.** There is no live split-button Swift type.

## Use it when…

Do not plan split-button UI against Droid yet. Use two [`MaterialButton`](button.md) controls side by side.

## How it behaves

There is no split-button constructor, split-region API, or dropdown bridge at this pin.
