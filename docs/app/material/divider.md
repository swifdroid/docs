# Divider

Material divider is a thin line that separates list items or sections.

**Droid does not wrap Material divider APIs at the current source pin.** There is no live Material divider Swift type.

## Use it when…

Do not plan Material divider UI against Droid yet. Use a spacer view or layout padding between rows.

## How it behaves

There is no divider constructor or inset API at this pin.
