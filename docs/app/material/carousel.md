# Carousel

Material carousels scroll a set of cards or media items with multi-item browsing.

**Droid does not wrap Material carousel APIs at the current source pin.** There is no live Material carousel Swift type.

## Use it when…

Do not plan Material carousel UI against Droid yet. Use a horizontal container you build yourself.

## How it behaves

There is no carousel constructor, page transformation API, or carousel callback at this pin.

## Notes

This page will grow only after a live Material carousel wrapper lands in a commit pin with real methods.
