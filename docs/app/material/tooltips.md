# Tooltips

Material tooltips show short helper text over a control.

**Droid does not wrap Material tooltip APIs at the current source pin.** There is no live Material tooltip Swift type.

## Use it when…

Do not plan Material tooltip UI against Droid yet. Use a visible [`TextView`](../classic/text-view.md) helper label under the control.

## How it behaves

There is no tooltip constructor, show/hide API, or tooltip listener at this pin.

## Notes

This page will grow only after a live Material tooltip wrapper lands in a commit pin with real methods.
